# Suomea

Небольшое веб-приложение с карточками для изучения финских слов.

## Структура проекта

```
Suomea/
├── index.html       # Разметка страницы
├── css/
│   └── style.css    # Стили
├── js/
│   └── app.js       # Логика карточек
├── data/
│   └── words.json   # Словарь: финское слово, перевод, категория, пример
└── README.md
```

## Запуск

Слова загружаются через `fetch`, поэтому страницу нужно открыть через локальный
сервер (при открытии `index.html` напрямую из файла браузер заблокирует запрос):

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Управление

- Клик по карточке, `Пробел` или `Enter` — показать перевод
- `←` / `→` — предыдущее / следующее слово
- «Перемешать» — случайный порядок карточек
- Выпадающий список — фильтр по категории

## Добавление слов

Добавьте объект в `data/words.json`:

```json
{ "fi": "aurinko", "ru": "солнце", "category": "Природа", "example": "Aurinko paistaa." }
```

Поле `example` необязательно. Новые категории появятся в списке автоматически.

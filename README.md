# Suomea

Мобильный прототип тренажёра финских слов: выбор перевода из четырёх вариантов,
произношение через синтез речи (fi-FI) и список всех слов.

## Структура проекта

```
Suomea/
├── index.html       # Разметка страницы
├── css/
│   └── style.css    # Стили
├── js/
│   ├── app.js       # Тренировка слов, список слов, навигация, озвучка
│   └── sentences.js # Составление предложений
├── tests/           # Автотесты Playwright
├── data/
│   ├── words.json     # Словарь: финское слово, перевод, группа
│   └── sentences.json # Предложения (глагол olla) и группы словоформ
└── README.md
```

## Запуск

Слова загружаются через `fetch`, поэтому страницу нужно открыть через локальный
сервер (при открытии `index.html` напрямую из файла браузер заблокирует запрос):

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Как устроена тренировка

- Каждое слово встречается 3 раза: дважды «русский → финский» и один раз «финский → русский».
- Одно и то же слово не идёт два раза подряд.
- Неверные варианты берутся из той же группы (`group`), чтобы задание было сложнее.
- После ответа финское слово произносится вслух; кнопка динамика повторяет его.
- Для озвучки явно выбирается финский голос (fi-FI): Satu в премиум/улучшенной
  версии, затем обычная Satu, затем любой другой финский голос. Список голосов
  браузер отдаёт с задержкой, поэтому приложение ждёт события `voiceschanged`.
  Если за 3 секунды финский голос не появился, показывается предупреждение.
- Три кружка над словом — три задания по этому слову. Неверный ответ ставит красный
  крестик, прогресс не растёт, а задание возвращается через несколько шагов.
  Когда на него ответят правильно, крестик меняется на синюю галочку.
- Прогресс внизу считает только верно выполненные задания. Урок заканчивается,
  когда все задания выполнены; на итоговом экране — точность и число ошибок.

## Урок: предложения

Вкладка «Предложения» — основная часть урока, после подготовки на словах.

- **Часть 1** — вопросы и утвердительные ответы, **часть 2** — вопросы и
  отрицательные ответы. В каждую часть случайно берутся 10 пар вопрос/ответ
  (всего в базе по 200 пар), вопрос всегда идёт перед своим ответом.
- Сверху — предложение на русском, ниже — места под слова. Финское предложение
  собирается по одному слову: для каждого места 4 варианта — правильная
  словоформа и 3 неверные из той же группы (`groups` в `sentences.json`).
- Нажатие на уже выбранное слово убирает его и все слова после него.
- Слова по одному не проверяются. Когда все места заполнены, появляется кнопка
  «Проверить»: проверяется всё предложение целиком, и в этот момент всегда
  звучит правильный вариант на финском.
- Неверно составленное предложение возвращается через несколько заданий;
  прогресс растёт только за верные.

Предложения взяты из «Olla — упражнения (200 пар)» и «Olla — отрицательные ответы (200 пар)».
Если в предложение добавляется новая словоформа, её нужно внести в одну из
групп `groups` — тест `sentences.spec.js` это проверяет.

## Добавление слов

Добавьте объект в `data/words.json`:

```json
{ "fi": "aurinko", "ru": "солнце", "group": "nature" }
```

Необязательное поле `rate` задаёт скорость произношения (по умолчанию 0.9).

## Тесты

Автотесты на [Playwright](https://playwright.dev) лежат в `tests/`:

- `words.spec.js` — проверка словаря (обязательные поля, нет повторов);
- `app.spec.js` — тренировка, ответы, список слов, экран окончания, ошибка загрузки;
- `sentences.spec.js` — данные предложений, сборка, проверка, части урока;
- `voice.spec.js` — выбор финского голоса и предупреждение (с подменой `speechSynthesis`).

Первый запуск:

```bash
npm install
npx playwright install chromium
npm test
```

Локальный сервер для тестов запускается автоматически (нужен `python3`).
Посмотреть тесты в браузере: `npx playwright test --headed` или `--ui`.

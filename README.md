# Suomea

Мобильный прототип тренажёра финских слов: выбор перевода из четырёх вариантов,
произношение через синтез речи (fi-FI) и список всех слов.

## Структура проекта

```
Suomea/
├── index.html            # Каркас страницы
├── css/style.css         # Стили
├── js/
│   ├── app.js            # Экраны, навигация, уроки, сохранение прогресса
│   ├── words.js          # «Учить новые слова»
│   ├── sentences.js      # Составление предложений
│   └── speech.js         # Озвучка: выбор финского голоса
├── data/
│   ├── lessons.json      # Список уроков
│   └── lessons/
│       ├── 1-words.json        # Слова урока 1
│       ├── 1-sentences.json    # Предложения урока 1 и группы словоформ
│       └── 1-description.html  # «Описание урока» / «Помощь»
├── tests/                # Автотесты Playwright
└── README.md
```

## Запуск

Слова загружаются через `fetch`, поэтому страницу нужно открыть через локальный
сервер (при открытии `index.html` напрямую из файла браузер заблокирует запрос):

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Экраны

- **Главный:** вкладки «Уроки» и «Словарь». У каждого урока кружок с рейтингом
  0–5: синий от 4.5, ниже — оранжевый. Закрытые уроки показаны с замком.
- **Урок:** подуроки с предложениями (1.1 «Вопрос + утверждение», 1.2 «Вопрос +
  отрицание»), «Учить новые слова» (кружок — процент пройденных слов),
  «Описание урока» (грамматика). Подурок 1.2 открывается при 4.5 в 1.1.
  Рейтинг урока в списке — среднее по подурокам.
- Прогресс (клетки, счётчики, процент слов) сохраняется в браузере (`localStorage`).

## Учить новые слова

- Каждое слово встречается 3 раза: дважды «русский → финский» и один раз «финский → русский».
- 6 вариантов ответа: неверные берутся из той же группы (`group`).
- После ответа финское слово произносится вслух; кнопка динамика повторяет его.
- Для озвучки явно выбирается финский голос (fi-FI): Satu в премиум/улучшенной
  версии, затем обычная Satu, затем любой другой финский голос. Список голосов
  браузер отдаёт с задержкой, поэтому приложение ждёт события `voiceschanged`.
  Если за 3 секунды финский голос не появился, показывается предупреждение.
- Три кружка над словом — три задания по нему. Неверный ответ ставит красный
  крестик, прогресс не растёт, задание возвращается через несколько шагов;
  после верного ответа крестик меняется на синюю галочку.

## Подуроки: предложения

- Подуроки задаются в `data/lessons.json` (`parts`): 1.1 — вопросы и
  утвердительные ответы, 1.2 — вопросы и отрицательные ответы.
- Сверху — предложение на русском, ниже голубое поле ответа (текст чёрный),
  ещё ниже 6 вариантов: правильная словоформа и 5 неверных из той же группы
  (`groups` в `1-sentences.json`, при нехватке — из группы `pad`).
- Слова по одному не проверяются. Когда предложение собрано, нужно нажать на
  пустое место экрана: проверяется всё предложение и всегда звучит правильный
  вариант на финском. Следующее нажатие — следующее предложение.
- **Верно:** посередине белого поля крупно похвала на финском, внизу мелко
  перевод (14 вариантов, подряд не повторяются).
- **Неверно:** поле прозрачно-красное, неверные слова ярко-красные, ниже на
  голубом фоне правильный ответ; посередине «Yritä uudelleen!», внизу
  «Попробуй снова!».
- «Ой, ошибся» убирает последнее слово; нажатие на слово в поле ответа убирает
  его и все слова после него. «Помощь» открывает описание урока.

### Клетки, круги и рейтинг

- Внизу 100 клеток — 100 предложений круга (50 пар вопрос/ответ). Текущая —
  тёмно-синяя, верный ответ — голубая, ошибка — красная; красная так и остаётся.
- Когда круг пройден, начинается следующий: пары с красными клетками
  возвращаются (цель — сделать клетку голубой), остальные меняются на новые
  пары из 200.
- Рейтинг: 0.1 звезды за каждые 2 голубые клетки, 5.0 — все 100 голубые, то
  есть 100 верных ответов подряд.
- При **4.5**: «Поздравляем, вам доступен следующий урок!» — перейти к
  следующему или довести этот урок до совершенства (продолжить).
- При **5.0**: «Поздравляем, урок пройден!» — можно продолжить.
  Каждое поздравление показывается один раз.

Предложения взяты из «Olla — упражнения (200 пар)» и «Olla — отрицательные ответы (200 пар)».
Если в предложение добавляется новая словоформа, её нужно внести в одну из
групп `groups` — тест `sentences.spec.js` это проверяет.

## Добавление слов

Добавьте объект в `data/lessons/1-words.json`:

```json
{ "fi": "aurinko", "ru": "солнце", "group": "nature" }
```

Необязательное поле `rate` задаёт скорость произношения (по умолчанию 0.9).

## Тесты

Автотесты на [Playwright](https://playwright.dev) лежат в `tests/`:

- `words.spec.js` — проверка словаря (обязательные поля, нет повторов);
- `navigation.spec.js` — главный экран, экран урока, описание, словарь, рейтинг;
- `app.spec.js` — «Учить новые слова»: ответы, повторы, прогресс, ошибка загрузки;
- `sentences.spec.js` — данные предложений, сборка, проверка, части урока;
- `voice.spec.js` — выбор финского голоса и предупреждение (с подменой `speechSynthesis`).

Первый запуск:

```bash
npm install
npx playwright install chromium
npm test
```

Локальный сервер для тестов запускается автоматически (нужен `python3`).
Посмотреть тесты в браузере: `npx playwright test --headed` или `--ui`.
